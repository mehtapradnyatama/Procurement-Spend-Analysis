# Company Purchasing Dataset

Creator: Shahriar Kabir.
Source: https://www.kaggle.com/datasets/shahriarkabir/company-purchasing-dataset
License reported by the publisher: CC0: Public Domain.

The publisher explicitly identifies these records as synthetic procurement transactions for a simulated mid-sized organization in 2024. This is not real-company transaction data.

The working CSV contains 500 rows and 9 columns. It was opened and saved through Excel during import preparation, so it is not an unchanged copy of the original download. The current file uses semicolon delimiters, decimal commas, and DD/MM/YY dates. Analysis and validation are documented in the project README and Excel workbook.
Columns: TransactionID, ItemName, Category, Quantity, UnitPrice, TotalCost, PurchaseDate, Supplier, Buyer.

Only this synthetic purchasing dataset is used in the project.
